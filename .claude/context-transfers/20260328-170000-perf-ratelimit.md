## Key Decisions

- **Shared CLOB circuit breaker (`clobRateLimit.js`)**: Single module with 60s auto-recovery, listener pattern for React subscription. All CLOB fetch paths check `isClobRateLimited()` before fetching and call `triggerClobRateLimit()` on 429.
- **Gamma rate limit handled separately in `useMarkets.js`**: Uses local state + `gammaTimerRef` with 30s recovery. Asymmetric with CLOB (different API, different recovery).
- **Parallel fetch with `CONCURRENCY=5`**: `fetchAllMarkets` fires 5 pages per batch via `Promise.all`. `effectivePageSize` detected from first successful (status 200, non-empty) page, not `results[0]`.
- **429 throw pattern**: All fetch wrappers (`fetchOrderBook`, `fetchPriceHistory`, `fetchMarketTrades`, `fetchResolvedPage`) throw errors with `.status = 429`. Callers catch and trigger circuit breaker.
- **Auto-refresh default ON**: `useAutoRefresh` defaults to `true` when no localStorage value exists.
- **UI constants in `uiConfig.js`**: `ROW_HEIGHT`, `HEADER_HEIGHT`, `FOOTER_HEIGHT`, `BANNER_HEIGHT`, fetch delays — single source of truth.

## Architecture & Design Context

- **Circuit breaker pattern**: `clobRateLimit.js` exports `isClobRateLimited()`, `triggerClobRateLimit()`, `clearClobRateLimit()`, `onClobRateLimitChange(fn)`. Components subscribe via `useEffect(() => onClobRateLimitChange(setClobRateLimited), [])`.
- **Background fetch effects in ResultsTable.jsx**: Two separate `useEffect` blocks handle spread and flow batch fetching. Both have CLOB rate limit guards at entry, in loops, and in catch blocks.
- **List height formula**: `containerHeight - HEADER_HEIGHT - FOOTER_HEIGHT - (clobRateLimited ? BANNER_HEIGHT : 0)`

## Traps & Failed Approaches

- ❌ **Using `results[0]` for effectivePageSize** — First page may be a failed request (status 0). Use `.find(r => r.status === 200 && r.data.length > 0)`.
- ❌ **Re-throwing all errors in fetchPriceHistory catch** — Breaks callers expecting `null` on failure. Only re-throw if `e?.status === 429`.
- ❌ **Fire-and-forget setTimeout for Gamma rate limit** — Leaks timer on unmount. Must use `useRef` + cleanup in useEffect return.
- ❌ **Duplicate string matches in TradeFlowEngine edits** — `const res = await fetch(url); if (!res.ok) continue;` matches 3 locations. Provide full function context for unique match.
