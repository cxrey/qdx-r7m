## Key Decisions

- **Replaced Immer `produce()` with plain `.map()` + identity check** in `useMarkets.js`: Immer proxy overhead caused 5-10s freeze on 13,500+ markets. The identity check pattern (`enriched !== m`) provides structural sharing without proxy traps.
- **Removed manual MutationObserver row observation** in `ResultsTable.jsx`: react-window v2 already handles row observation internally via its built-in layout effect. The duplicate system created a race condition causing expanded rows to collapse during scroll.
- **`peekCachedTradeFlow` vs `getCachedTradeFlow`**: `peek` is read-only (no LRU promotion) for filter/render paths. `get` promotes LRU for active user access (TradeFlowPanel).
- **Shared color constants** (`CYAN`, `PINK`, `PURPLE`, `AMBER`, `RED`) live in `src/uiConfig.js`. Tailwind arbitrary-value classes (`text-[#00d4aa]`) stay as static strings since Tailwind needs them for purging.
- **`perPage` key retained** in `filterDefaults.js` for localStorage backward compatibility, but UI dropdown removed.

## Traps & Failed Approaches

- :x: **Spreading Immer draft proxies** (`{ ...proxy, ... }`) is ~100x slower than plain objects due to proxy trap accesses. 13,500 markets x 30 properties x 2 spreads = ~810,000 proxy traps.
- :x: **Adding a second `data-react-window-index` div** inside VirtualRow duplicates the attribute react-window sets on the outer wrapper, causing `querySelectorAll` to match wrong elements during observation.
- :x: **Manual MutationObserver + observeCurrentRows** in ResultsTable.jsx races with react-window's built-in layout effect — during cleanup/re-observe gap, height cache can lose expanded row's ~13,000px measurement, falling back to 44px default.
